# Release Notes - WhatsLink+ v2.6.0 (Phase 1 Complete)

## 📅 Date: January 23, 2026

## 🎯 Overview

This release marks the completion of **Phase 1: Foundation & Quick Wins**. It introduces a complete overhaul of the user interface, incorporating a modern sidebar layout, comprehensive settings (Theme, Language, Privacy), and a robust sharing system. Significant architectural improvements have been made to tab management and internationalization support.

## 🐛 Bug Fixes & Performance Improvements

### 1. Enhanced WhatsApp Tab Management

**File**: `source/background.js`

**Problem**: Previous behavior always created a new tab for WhatsApp Web, leading to clutter and potential session issues.
**Solution**: Implemented logic to check for existing `web.whatsapp.com` tabs before creating a new one. If found, the extension updates the existing tab instead of opening a duplicate.

**Code Change**:

```javascript
// Before:
await chrome.tabs.create({ url });

// After:
if (finalService === 'web') {
  const existingTabs = await chrome.tabs.query({ url: 'https://web.whatsapp.com/*' });
  if (existingTabs.length > 0) {
    await chrome.tabs.update(existingTabs[0].id, { url: url, active: true });
  } else {
    await chrome.tabs.create({ url });
  }
}
```

**Impact**: Improved user experience by reusing open tabs and reducing browser memory usage.

---

### 2. Help Section Refactor

**File**: `source/popup.html`, `source/popup.css`

**Problem**: The Help section used simple anchor links that looked inconsistent with the new button-based design system.
**Solution**: Refactored to use a button-based menu (`settings-menu-btn`) with Material Icons, matching the Settings interface.

**Visual Updates**:

- Replaced standard `<a>` tags with `<button>` elements.
- Added icons: `info`, `code`, `bug_report`, `lightbulb`.
- Standardized hover effects and spacing.

---

### 3. Flag SVGs and Fallback

**Files**: `source/images/flags/*.svg`

**Problem**: Missing flag icons for several countries caused broken images in the country selector.
**Solution**: Added 28+ missing SVG flags (MX, ES, BR, US, etc.) and implemented a fallback mechanism.

## 🎁 New Features

### 1. Share Modal System

**Files**: `source/popup.html`, `source/popup.js`, `source/popup.css`

A brand new, platform-agnostic share modal that allows users to share WhatsLink+ seamlessly.

**Features**:

- **Platform Support**: X (Twitter), Instagram, Threads, LinkedIn.
- **Pre-filled Content**: Platform-specific marketing copy defined in `_locales`.
- **Visuals**: Glassmorphism effect (`backdrop-filter`), smooth `slideUp` animations, and brand-colored hover states.

**Implementation**:

```javascript
// popup.js - handleShare
const shareMessages = {
  x: `${chrome.i18n.getMessage('shareMessageX')}\n\n${webStoreUrl}`,
  linkedin: chrome.i18n.getMessage('shareMessageLinkedIn'),
  // ... other platforms
};

switch(platform) {
  case 'x':
    chrome.tabs.create({ url: `https://twitter.com/intent/tweet?text=${twitterText}` });
    break;
  case 'instagram':
    navigator.clipboard.writeText(shareMessages.instagram);
    // Shows toast feedback
    break;
}
```

---

### 2. Comprehensive Privacy Controls

**Files**: `source/privacy/*`, `source/popup.html`

Integrated advanced privacy features directly into the popup interface.

**Capabilities**:

- **Master Toggle**: Enable/Disable all privacy effects globally.
- **Granular Control**: Blur settings for Messages, Names, Media, Profile Pictures, and more.
- **Architecture**: Modular CSS injection system (`source/privacy/css/*.css`) managed by `privacyContent.js`.

**Storage Structure**:

```javascript
privacySettings: {
  on: boolean, // Master switch
  blurMessages: boolean,
  blurName: boolean,
  blurMedia: boolean,
  // ...
}
```

### 3. Internationalization (i18n) & Spanish Support

**Files**: `source/_locales/es/messages.json`

**Changes**:

- Added full Spanish (`es`) locale support.
- Centralized 22+ new strings for the Share Modal and Referral system.
- Fixed `i18n` API usage in `utils.js` to prevent runtime errors with localized strings.

## 🔒 Security

### Permissions Update

- **`tabs`**: Enhanced usage for checking existing WhatsApp tabs (`chrome.tabs.query`).
- **`clipboardWrite`**: Used via `navigator.clipboard` for "Copy Link" and Instagram/Threads sharing (user-triggered).
- **Rationale**: All permissions are strictly scoped to user actions within the popup or background tasks initiated by the user.

## 📝 Development Notes

### Key Architecture Decisions

1. **Privacy as a Module**: Privacy features were isolated in `source/privacy/` to maintain clean separation of concerns from the main message logic.
2. **Glassmorphism UI**: High-end visual fidelity was prioritized using `backdrop-filter` and semi-transparent backgrounds to give a "Premium" feel.
3. **Optimized Tab Reuse**: To prevent the "too many tabs" problem common with heavy WhatsApp users.
