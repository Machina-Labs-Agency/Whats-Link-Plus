# Release Notes

## v2.6.0 - 2026-01-23

This release marks the completion of **Phase 1: Foundation & Quick Wins**. It introduces a complete overhaul of the user interface, incorporating a modern sidebar layout, comprehensive settings (Theme, Language, Privacy), and a robust sharing system. Significant architectural improvements have been made to tab management and internationalization support.

### Added

* **Enhanced WhatsApp Tab Management:** Improved logic to check for existing `web.whatsapp.com` tabs before creating a new one. If found, the extension updates the existing tab instead of opening a duplicate, reducing clutter and memory usage.
* **Share Modal System:** A brand new, platform-agnostic share modal that allows users to share WhatsLink+ seamlessly to X (Twitter), Instagram, Threads, and LinkedIn with pre-filled content.
* **Comprehensive Privacy Controls:** Integrated advanced privacy features directly into the popup interface, including a master toggle and granular controls for blurring Messages, Names, Media, and Profile Pictures.
* **Internationalization (i18n) & Spanish Support:** Added full Spanish (`es`) locale support and centralized 22+ new strings for the Share Modal and Referral system.
* **Flag SVGs and Fallback:** Added 28+ missing SVG flags (MX, ES, BR, US, etc.) and implemented a fallback mechanism for the country selector.

### Changed

* **Help Section Refactor:** Refactored the Help section to use a button-based menu (`settings-menu-btn`) with Material Icons, matching the new Settings interface for a consistent design system.
* **Glassmorphism UI:** Prioritized high-end visual fidelity using `backdrop-filter` and semi-transparent backgrounds to give the extension a "Premium" feel.

### Fixed

* **Tab Duplication:** Fixed the issue where clicking the extension icon always created a new WhatsApp Web tab.
* **Broken Images:** Fixed missing flag icons in the country selector by adding proper SVGs and fallbacks.
* **Runtime Errors:** Fixed `i18n` API usage in `utils.js` to prevent runtime errors with localized strings.
